### 🔭 My projects

* [STNDRD](https://play.google.com/store/apps/details?id=uni.cbum) — 100k+ installs
Training app built with 6× Mr. Olympia Chris Bumstead. Technical lead directing
two developers across a Flutter mobile app and a Next.js web app on shared
Firebase services. Owned architecture and the iOS/Android release process.

* [OTTAA Project](https://github.com/OTTAA-Project) — 2021–2024
Open-source predictive communication platform for speech-impaired children.
Built from zero to a six-figure user base as sole front-end and back-end
engineer on a four-person team, and drove its
[Digital Public Good](https://digitalpublicgoods.net/registry/) certification
end to end.

* **GoalSquare** — live, paid
Goalkeeper coaching product on mobile and Windows. Postgres with row-level
security, GoTrue auth, Edge Functions for server-side generation and PDF
export, and billing unified across Apple IAP, Google Play Billing and Stripe.
Modelled and migrated ~1,265 multilingual exercise records across 9 languages
out of a legacy database.

* **Beautiful Places** — 2024
Client app taken from empty repo to App Store approval in two weeks. Image
classification runs entirely on-device via TFLite, with no data sent to a cloud
model; results persist through an AWS function and render on an in-app map.

* **GoalSquare Plan** — in development
Session-planning SaaS on React / Vite / TypeScript. I specified the
requirements, designed the build flow, and orchestrated Claude Code to
implement it end to end, working as architect and reviewer over the agent's
output.

### 🏦 At work

Senior Application Developer at **Commercial Bank of Qatar**, leading 5 of 10
front-end engineers across four products: corporate internet banking (CIB),
digital account opening (DAO), CB Trade, and an internal survey platform.

Re-architected a legacy .NET MVC banking platform into a modular Flutter
codebase for iOS, Android and web, and restructured API request patterns to cut
load times roughly 50%. Own the release process end to end on Azure DevOps CI/CD,
and L1/L2 support for corporate banking clients.
